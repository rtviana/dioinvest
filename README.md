# dioinvest
Simulador de investimento mensal em FIIs. Sugere o aporte a partir do salário, projeta patrimônio e dividendos com juros compostos e compara cenários de 2 a 30 anos, já descontada a inflação. Também distribui o aporte entre seis tipos de FII conforme o perfil do investidor, com validações automáticas.
